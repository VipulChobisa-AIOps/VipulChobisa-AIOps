# ReelScript - Viral Content Studio

A specialized video-to-script engine designed for content creators focused on Reels and Shorts. Transforming your raw social media links and transcripts into viral Hindi and English video scripts with one-click export functions.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   `npm run dev`
